# METAL RACER — онлайн-комнаты

## Запуск
1. Установи Node.js на хостинге (например, Replit).
2. Загрузи содержимое этой папки в проект.
3. В терминале выполни `npm install`.
4. Запусти `npm start`.
5. Открой опубликованный URL проекта. Игроки должны использовать один и тот же URL.

## Что добавлено
- Создание комнаты с пятизначным кодом.
- Вход по коду.
- Комнаты максимум на двух игроков.
- Хозяин комнаты запускает гонку для обоих.
- Позиция машины второго игрока передаётся через Socket.IO.

## Важно
Комнаты хранятся в памяти сервера. Если сервер перезапустится, комнаты исчезнут.
Игра должна открываться через серверный URL, а не как локальный HTML-файл.
